# Habitat

A PWA habit and task tracker. Dark, cold-grey design system. Offline-first, installable as a native-feeling iPhone app via "Add to Home Screen" in Safari.

> This is a recreation of a personal Android app ("Forge") as a cross-platform PWA.

## Stack

| Package | Purpose |
|---|---|
| Vite + React + TypeScript | Build system + UI framework |
| Tailwind CSS v4 | Utility-first styling (CSS-first config) |
| react-router-dom | Client-side routing (5 screens) |
| Dexie (IndexedDB) | Offline-first database |
| dexie-react-hooks | Live reactive queries |
| vite-plugin-pwa | PWA manifest + service worker |
| framer-motion | Animations |
| lucide-react | Icons |
| date-fns | Date manipulation |
| @fontsource/roboto | Self-hosted Roboto font |
| vitest | Unit testing |

## Development

```bash
npm install        # Install dependencies
npm run dev        # Dev server at http://localhost:5173
npm test           # Run vitest unit tests
npm run build      # Production build (outputs to dist/)
npm run preview    # Preview the production build locally
```

## Deploy to Vercel

1. Push to GitHub
2. Import the repo in [vercel.com](https://vercel.com)
3. Framework preset: **Vite** (auto-detected)
4. No environment variables needed
5. Click **Deploy**

The included `vercel.json` handles SPA routing (all paths → `index.html`).

## PWA / iPhone Install

After deploying:
1. Open the Vercel URL in Safari on iPhone
2. Tap the Share button → "Add to Home Screen"
3. The app installs as a standalone app with no browser chrome

Offline caching is handled by the service worker generated by `vite-plugin-pwa`. When a new deploy is available, a dark **"New version ready · Tap to update"** banner appears so updates never interrupt typing.

## Backup & Restore

All data lives locally on your device inside IndexedDB (no backend or cloud sync):

1. Open **Profile → Your Data**
2. Tap **Export backup** (on iPhone, this opens the Share sheet so you can save `habitat-backup-yyyy-MM-dd.json` to Files)
3. To restore, tap **Import backup**, select the JSON file, review the summary, and confirm
4. Before any import or erase, Habitat saves a safety snapshot (`lastBeforeRestore`) in IndexedDB — tap **Undo last import** if you need to revert

## Known Limits

- **No phone push notifications yet:** Smart Habit Scheduler saves your preferred reminder times locally, and the Test Lab shows in-app preview banners. OS-level push notifications are planned for a later update.
- **Boss Mode:** Currently shows an Under Construction screen while the core habit, task, and analytics flows are finalized.

## Design System

**Colors:** Cold obsidian dark theme. Signature orange `#FF6A00`. No brownish tints.

See `src/index.css` for all Tailwind theme tokens. Full color reference in `docs/REFERENCE-NOTES.md`.

**Dates:** All dates stored as local `yyyy-MM-dd` strings. The streak calculator uses local time throughout (important for UTC+3 users). Never use `toISOString()` for date keys.
